# Blogs Web Client

The React and Material UI client for the [Full-Stack Blogging Platform](../README.md).

## Setup

```bash
cp .env.sample .env
yarn install
yarn start
```

`REACT_APP_API_URL` must point to the backend API; the sample uses `http://localhost:8080/api`.

## Tests

```bash
yarn test
```

See the root README for the product workflow, architecture, backend setup, and current security boundaries.
